Technical Interview Scorecard Template

Most technical interviews fail on consistency, not difficulty. Use this scorecard so every interviewer scores the same way.

1. Score 5 skills, 1 to 5

SkillWhat to look forScore
Problem solvingBreaks the problem down before coding
Code qualityReadable names, handles edge cases
DebuggingFinds and fixes bugs with a clear method
System designExplains trade-offs
CommunicationThinks out loud, asks clarifying questions

2. Define each score level

1 = needs heavy help · 3 = solves with minor hints · 5 = solves and explains trade-offs.

3. Ask one follow-up per answer

"Why this approach?" separates memorized answers from real reasoning.

4. Write evidence, not opinions

"Used a hash map, explained O(n)" beats "seemed strong".

5. Calibrate monthly

Have two interviewers score the same recording and compare.
