# Technical Interview Scorecard Template

A free scorecard so every interviewer, **in-house or outsourced**, scores candidates against the same bar.

📄 Download: [`scorecard.csv`](scorecard.csv) (opens in Excel or Google Sheets)

## How to use
1. Pick 4–5 skills for the role before interviewing.
2. Score each skill 1–4.
3. Write **evidence**, not adjectives.
4. Decide with the rule below.

## Scoring levels
| Score | Meaning |
|---|---|
| 1 | Can't explain their own solution |
| 2 | Explains what, not why |
| 3 | Explains why and names a trade-off |
| 4 | Compares options and adapts when constraints change |

## Decision rule
- **Advance:** average 3+, no skill below 2
- **Discuss:** average 2.5–3, or one skill at 1
- **Don't advance:** average below 2.5

## Evidence examples
| Weak | Strong |
|---|---|
| "Good problem solver" | "Picked a heap for top-k and explained O(n log k) vs sorting" |
| "Communication OK" | "Raised edge cases before coding, unprompted" |
